# 🌡️ Temperature Converter

A simple and user-friendly temperature converter built using HTML, CSS, and JavaScript.

## ✨ Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Simple and clean user interface
- Instant conversion using JavaScript
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

This project was created to practice JavaScript logic, user input handling, and basic front-end development.
